# Спаси школьный портал

Проба по восстановлению информационной системы. Нужно разобраться, почему не открывается расписание, исправить сбой и настроить профилактику. Знания Linux не нужны.

## Как открыть

Готовая версия на сервере: https://31-76-227-64.sslip.io/portallab/

Для запуска этой копии на компьютере открой терминал в общей папке «Профпробы» (на уровень выше этой папки). На компьютере, который раздаёт пробы, нужен Python 3. Выполни:

```sh
python3 -m http.server 8080
```

Открой в браузере: http://localhost:8080/portallab/

Держи терминал открытым во время работы. Остановка сервера — Ctrl+C. Если команда python3 не найдена или используется Windows, смотри общий README в папке «Профпробы».

## Что делать ученику

1. Исследуй портал и выполняй задания шести этапов.
2. Со второго этапа вводи простые команды в учебном терминале. Примеры и объяснения есть слева. Enter выполняет команду.
3. «Далее» проверяет задание и открывает следующий этап. В конце нажми «Завершить», чтобы получить отчёт.

## Как начать заново

Нажми кнопку со стрелкой сброса вверху («Начать заново») и подтверди.

Обновление страницы сохраняет прогресс текущей вкладки. Перед следующим учеником используй сброс.

Это готовая сборка сайта. Открывай её через сервер, а не двойным кликом по index.html. Файлы JS, CSS и папки с ресурсами нужны для работы; переименовывать их не надо.

Команды работают только с виртуальной системой внутри браузера. Настоящие файлы компьютера они не меняют.
